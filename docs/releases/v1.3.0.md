# Better Music Overlay 1.3.0

A customizable Fabric music HUD for Windows, with smooth typography, native media controls, and optional lyrics.

## Download and install

Download **one** JAR matching your Minecraft version: 1.21.11, 26.1, 26.1.1, 26.1.2, 26.2, or 26.3. Install Fabric Loader 0.19.5 or newer and the matching Fabric API, then put the JAR in your instance's `mods` folder. Remove older Better Music Overlay JARs before upgrading.

Minecraft 1.21.11 requires Java 21 or newer; 26.x requires Java 25 or newer. Media integration currently supports Windows 10/11. Players must publish a Windows media session.

## What's included

- Studio, Aurora, Compact, and Minimal layouts, plus Vinyl and Lyric Lounge scenes.
- Smooth Inter typography, album colors, artwork transitions, themes, profiles, and a draggable/resizable HUD.
- Native player selection, playback controls, seeking where supported, optional music ducking, and streamer privacy controls.
- Local LRC and Enhanced LRC; optional LRCLIB lookup with explicit online consent.
- Full lyrics reader with automatic following, line seeking, plain-text fallback, and saved per-song timing adjustments.

## Fixed in 1.3.0

- Choosing a layout now disables Smart collapse so the HUD does not revert to Minimal. Use **O → Identity → Aurora** to select an expanded scene.
- Playback time advances when a player omits the total duration.
- Commands target the displayed player; automatic selection stays with the active playing session.
- Cancelled lyric searches cannot restore stale candidates. Plain lyrics survive an unavailable synchronized search.
- Timing adjustments apply immediately without downloading the lyrics again.
- Mouse controls work with Minecraft 26.3's SDL button numbering.

Open the studio with **O**, quick controls with **M**, and the reader through **O → Lyrics → Open lyrics reader**.

## Verification

37 automated tests passed for each of the six targets (222 passes). The optional live LRCLIB test passed separately. Actual 1.21.11 and 26.3 client UI checks covered layout selection, delayed HUD rendering, and reader timing controls. SHA-256 checksums are attached.

Online lyrics coverage and timing depend on the recording. Plain-text lyrics are displayed without invented timestamps. macOS and Linux media backends are not included.
