# Better Music Overlay 1.4.0

The music studio now has sidebar navigation, rounded controls, switches, and a dedicated live preview. The lyrics reader and advanced settings use the same design, including compact layouts for small windows.

## Lyrics

- LRCLIB integration now reads Lyricsfile 1.0 and supplied word timestamps, alongside line-synced LRC and plain text. Word highlighting works in the HUD and reader when the recording provides timing.
- Alternate recordings distinguish WORDS, SYNC, and PLAIN. Invalid or unsupported rich data falls back to legacy lyric fields.
- Request identification, a 250 ms gap between requests, content-type checks, and complete Retry-After cooldowns follow the current LRCLIB documentation.
- Import local `.lrc` or `.txt` files by dropping them onto the import screen, or paste lyrics from the clipboard. Preview before saving; previous local files receive a `.bak` backup.

Enable **O → Lyrics → LRCLIB lookup** for online lyrics. No API key is needed. Lyrics availability and timing vary by recording. Local files take priority, and plain text receives no artificial timing.

## Performance

- Reused image and pixel buffers, cached backgrounds and UI surfaces, and bulk pixel uploads reduce rendering work and allocations.
- **O → Advanced → Rendering** adds Quality / Balanced / Saver presets with overlay limits of 30 / 20 / 10 fps. Balanced is the default. Minecraft's own frame limit is unaffected.
- With Motion off, unchanged cards skip painting.
- A focused local raster benchmark measured approximately 97% less Java allocation with buffer reuse. This does not establish an in-game FPS increase. [Measurement details](https://github.com/LootingVI/BetterMusicOverlay/blob/v1.4.0/docs/PERFORMANCE.md).

## Install

Download **one** JAR matching Minecraft **1.21.11, 26.1, 26.1.1, 26.1.2, 26.2, or 26.3**. Install Fabric Loader 0.19.5 or newer and the matching Fabric API. Replace the previous Better Music Overlay JAR in your instance's `mods` folder.

Minecraft 1.21.11 requires Java 21 or newer; 26.x requires Java 25 or newer. Native media integration supports Windows 10/11 and players that expose Windows media sessions. Your existing settings and appearance remain usable.
