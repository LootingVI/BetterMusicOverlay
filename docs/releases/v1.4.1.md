# Better Music Overlay 1.4.1

Fixes missing LRCLIB lyrics caused by differences in album metadata, particularly with Apple Music.

- Fallback search no longer filters out recordings because of a different album name. Album names now help rank otherwise matching results.
- Apple Music's `- Single` and `- EP` album suffixes are recognized when ranking results and removing an independently confirmed album suffix from the artist.
- Players that omit duration now get a search fallback. Conflicting recording lengths still require manual selection.
- An unsuccessful automatic lookup now points to **Find recording**, rather than claiming no lyrics exist.
- Song title, artist, live/remix qualifiers, and the two-second tolerance for known playback durations remain checked.

The reported **GERÄT (bitte cancelt mich 2)** / **Zensery** case was reproduced with a failing regression test. After the fix, a live lookup using Apple Music's public track metadata loaded synchronized lyrics from [LRCLIB record 32429053](https://lrclib.net/api/get/32429053).

Download one JAR for your Minecraft version and replace the old Better Music Overlay JAR in `mods`. Restart Minecraft, then enable **O → Lyrics → LRCLIB lookup**. Existing settings remain compatible.

Builds: **1.21.11, 26.1, 26.1.1, 26.1.2, 26.2, 26.3**. Fabric Loader and the matching Fabric API are required. Native media integration supports Windows 10/11.

Verification: **58 tests per target, 348 passes, zero failures**. Two separate live LRCLIB checks passed, including the reported recording. The six release JARs were checked for their version/target metadata, dependencies, exclusion of the development smoke harness, and SHA-256 checksums.
