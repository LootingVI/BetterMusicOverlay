# Better Music Overlay 1.4.2

Fixes Apple Music on Windows sending `Artist — Album - Single` as the artist while leaving the album field empty. Previous versions searched for the combined artist and rejected otherwise matching lyrics. Version 1.4.2 separates this Apple Music metadata into the artist and album used for lookup and ranking. Local lyric filenames and saved corrections stay compatible.

- **Find recording** falls back to a title-only search when the artist search returns no records. This makes differently credited entries available for manual selection. The chosen recording is saved for the track.
- **Copy diagnostics** in the lyrics reader copies the mod version, raw and normalized metadata, status, and request results. It excludes lyrics, artwork and local paths; Streamer mode redacts track details. Nothing is uploaded automatically.
- Automatic matching still checks the title, artist, recording qualifiers, and the two-second tolerance for a known duration. A broader manual search does not automatically select a different artist.

Replace the previous Better Music Overlay JAR in `mods` with the JAR for your Minecraft version, then restart Minecraft. Enable **O → Lyrics → LRCLIB lookup**. Enable **Show lyrics** for the HUD, or open the lyrics reader independently.

For an artist alias mismatch, open **Lyrics reader → Find recording**, click **Search alternate recordings**, cycle through the candidates and select **Use displayed recording**. If lookup still fails, use **Copy diagnostics** and inspect its current-track metadata before sharing it.

Builds: **1.21.11, 26.1, 26.1.1, 26.1.2, 26.2, 26.3**. Fabric Loader and the matching Fabric API are required. Native media integration supports Windows 10/11.
